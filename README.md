# Prediction Market Agents Skill

A Claude skill that provides a strategic framework for building and monetizing AI agents that operate on prediction markets (Polymarket, Kalshi, and others).

## What's Inside

- **SKILL.md** — Core skill file covering agent architecture, strategy selection, position management, business models, and ecosystem tooling
- **references/deep-reference.md** — Deep dive into Kelly Criterion math, strategy suitability matrix, full project directory with links, and platform comparisons

## Key Topics

- Four-layer agent architecture (Information → Analysis → Strategy → Execution)
- Strategy framework: deterministic arbitrage as core, structured info as supplement
- Position management via confidence tiers
- Business model paths: infrastructure B2B, strategy SaaS, vault/asset management
- Current tooling ecosystem and where the gaps are

## Install

Add the `prediction-market-agents.skill` file to your Claude skill set, or drop the folder into your skills directory.
